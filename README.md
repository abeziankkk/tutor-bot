# Telegram-бот репетитора

Бот-визитка: отвечает на `/start` и показывает меню с кнопками **Цены** и **Контакты**. Нужен, чтобы ученик быстро посмотрел стоимость урока и способ связи, не переписываясь вручную.

Стек: Python, `python-telegram-bot`, токен берётся из `.env` через `python-dotenv`.

## Что умеет

| Действие | Что происходит |
|---|---|
| `/start` | Приветствие и главное меню |
| Кнопка «Цены» | Текст с примером тарифов |
| Кнопка «Контакты» | Username для связи |
| Повторный клик по той же кнопке | Ничего не ломается: Telegram ругается, если текст не изменился, ошибка глушится |

Меню остаётся под сообщением после каждого нажатия, так что можно переключаться между ценами и контактами.

Тексты сейчас заглушки. Их нужно поменять в `bot.py`:

- цены — в ветке `query.data == "prices"`;
- контакт — в ветке `query.data == "contacts"` (сейчас там `@твой_username`).

## Запуск

Нужны Python 3.9+ и токен бота от [@BotFather](https://t.me/BotFather).

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. В корне проекта создать файл `.env`:

```
BOT_TOKEN=токен_от_BotFather
```

3. Запустить:

```bash
python bot.py
```

В консоли появится `Бот запущен`. Дальше бот работает в режиме polling: сам ходит в Telegram за обновлениями, отдельный сервер и webhook не нужны.

Если токена нет, процесс сразу завершится с сообщением `Не найден BOT_TOKEN в файле .env`.

## Как устроен код

Всё в одном файле `bot.py`.

- `main_menu()` собирает инлайн-клавиатуру.
- `start()` отвечает на команду `/start`.
- `button()` обрабатывает нажатия: смотрит `callback_data` (`prices` / `contacts`) и правит то же сообщение.
- `main()` проверяет токен, вешает хендлеры и стартует polling.

`.gitignore` уже исключает `.env`, токен в git не попадёт.
