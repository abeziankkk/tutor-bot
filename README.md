# Telegram-бот репетитора

Бот-визитка: отвечает на `/start` и показывает меню с кнопками **Цены**, **Контакты** и **Записаться на пробный урок**. Нужен, чтобы ученик быстро посмотрел стоимость, способ связи или оставил заявку.

Стек: Python, `python-telegram-bot`. Токен и ID админа берутся из `.env` через `python-dotenv`.

## Что умеет

| Действие | Что происходит |
|---|---|
| `/start` | Приветствие и главное меню |
| Кнопка «Цены» | Текст с примером тарифов |
| Кнопка «Контакты» | Username для связи |
| Кнопка «Записаться на пробный урок» | Диалог: имя → удобное время → заявка уходит админу |
| `/cancel` | Отмена записи в любой момент диалога |
| Повторный клик по той же кнопке цен/контактов | Ничего не ломается: Telegram ругается, если текст не изменился, ошибка глушится |

Меню остаётся под сообщением после цен и контактов, так что можно переключаться между ними.

Тексты-заглушки нужно поменять в `bot.py`:

- цены — в ветке `query.data == "prices"`;
- контакт — иначе в `button()` (сейчас там `@твой_username`).

## Запуск

Нужны Python 3.9+ и токен бота от [@BotFather](https://t.me/BotFather). Свой Telegram ID (число) можно узнать у [@userinfobot](https://t.me/userinfobot).

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. В корне проекта создать файл `.env`:

```
BOT_TOKEN=токен_от_BotFather
ADMIN_ID=твой_telegram_id
```

`ADMIN_ID` — куда бот шлёт заявки на пробный урок. Без него процесс не стартует.

3. Запустить:

```bash
python bot.py
```

В консоли появится `Бот запущен`. Дальше бот работает в режиме polling: сам ходит в Telegram за обновлениями, отдельный сервер и webhook не нужны.

Если нет `BOT_TOKEN` или `ADMIN_ID`, процесс сразу завершится с сообщением об ошибке.

## Как устроен код

Всё в одном файле `bot.py`.

- `main_menu()` собирает инлайн-клавиатуру.
- `start()` отвечает на команду `/start`.
- `button()` обрабатывает «Цены» и «Контакты» и правит то же сообщение.
- `ConversationHandler` ведёт запись: `signup_start` → `get_name` → `get_time`. Готовая заявка уходит в чат `ADMIN_ID`.
- `cancel()` выходит из диалога по `/cancel`.
- `main()` проверяет токен и ID админа, вешает хендлеры и стартует polling.

`.gitignore` уже исключает `.env`, секреты в git не попадут.
